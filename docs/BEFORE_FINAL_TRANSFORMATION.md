# Before final transformation

The starting project was a local FastAPI/Jinja prototype with SQLite, synthetic cases, explainable metrics, a rule-based risk engine, VADER sentiment, SQL/Power BI/Postman/Selenium/Azure materials, and two passing unit tests. Its main limitation was that it presented mostly pre-generated case records and did not yet demonstrate event ingestion, local assistant grounding, or a clear zero-cost architecture. The transformation preserves the working stack and adds those capabilities incrementally.
