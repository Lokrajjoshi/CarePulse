# Beginner exploration path

In 30-45 minutes: run the app; open the dashboard; inspect `/cases`; open a case in agent and customer views; visit `/docs`; read `src/risk_engine.py`; read one SQL query; inspect `src/metrics.py`; then review the Power BI model, Selenium README, and Azure architecture. Learn Python/SQL first, then FastAPI, HTML/CSS, JavaScript, Power BI, Selenium, Postman, Azure, Git, and pytest.
