# Power BI setup

Power BI Desktop is optional. Use **Get data > Text/CSV** for exports in `data/exports` (when generated), or **Get data > PostgreSQL database** for a configured PostgreSQL instance. Create one-to-many relationships from Customers to Cases and Cases to Interactions, Promises, Interventions, and Feedback. Add slicers for date, industry, channel, issue, priority, sentiment, and risk. No `.pbix` is included because this environment cannot genuinely create and validate Power BI Desktop files.
